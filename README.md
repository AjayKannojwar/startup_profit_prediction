# startup_profit_prediction
## 📌 Project Overview


**Startup Profit Prediction** is a Machine Learning regression project that predicts the **profit of a startup** based on its expenditure and other business-related factors.


The project uses historical startup data to understand the relationship between different types of investments and the resulting profit. Various regression algorithms are trained and evaluated to identify a suitable model for profit prediction.


---


## 🎯 Objectives


* Analyze startup investment and profit data.
* Perform data preprocessing and exploratory data analysis.
* Identify important features affecting startup profit.
* Train different Machine Learning regression models.
* Evaluate model performance using appropriate metrics.
* Predict the expected profit of a new startup based on its investments.


---


## 📊 Dataset


The dataset contains information about startups and their expenditures.


### Main Features


| Feature           | Description                               |
| ----------------- | ----------------------------------------- |
| `R&D Spend`       | Amount spent on Research and Development  |
| `Administration`  | Administrative expenditure                |
| `Marketing Spend` | Marketing and promotional expenditure     |
| `State`           | State/location where the startup operates |
| `Profit`          | Profit generated by the startup           |


### Target Variable


`Profit`


The target variable is continuous, making this a **Regression Problem**.

## 📏 Model Evaluation


Regression models can be evaluated using:


### Mean Absolute Error (MAE)


Measures the average absolute difference between actual and predicted values.


### Mean Squared Error (MSE)


Measures the average squared difference between actual and predicted values.


### Root Mean Squared Error (RMSE)


The square root of MSE and represents prediction error in the same unit as the target.


### R² Score


Measures how well the model explains the variation in startup profit.


A higher **R² score** generally indicates better model performance.
